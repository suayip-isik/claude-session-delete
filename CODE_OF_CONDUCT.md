# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone who takes part in this project's issues, pull requests, discussions and other spaces is expected to follow it.

In short: be welcoming, respectful and constructive, and assume good faith. Harassment, insults and personal attacks are not tolerated.

## Reporting

Report unacceptable behaviour to the maintainer, Şuayip Işık, at suayip.isik.16@gmail.com. All reports are reviewed promptly and handled confidentially. The maintainer will respond as described in the Covenant's [Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
